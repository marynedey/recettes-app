# Mes Recettes

Application web (PWA) de recettes de cuisine, pensée pour le téléphone : recherche, recalcul des portions, mode cuisine avec minuteurs et écran toujours allumé, import par lien. Fonctionne hors ligne en lecture.

Les recettes ne sont **pas** dans ce dépôt : l'app les lit dans un dépôt GitHub privé, avec un jeton personnel stocké uniquement sur l'appareil.

- Guide d'installation : [GUIDE.md](GUIDE.md)
- Notes techniques : [CLAUDE.md](CLAUDE.md)

Aucune dépendance, aucune étape de build : servir le dossier tel quel (GitHub Pages, `python3 -m http.server`…).
